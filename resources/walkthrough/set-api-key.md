The extension uses your own DeepSeek API key to add DeepSeek V4.1 Flash and V4 Pro to the Copilot Chat model picker. Paste it once; update or remove it later from the Command Palette.

- `Ctrl/Cmd + Shift + P` → `Multi-Model: Set API Key`
- `Multi-Model: Clear API Key` removes it
- `Multi-Model: Get API Key` opens the DeepSeek key page
